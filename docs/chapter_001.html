I Came to Another World, But I Can Only Use Lifestyle Magic

Published as a book by Mag Garden Corporation.

I was just an ordinary office worker, but when I woke up, I had become Patience Granger.

This Granger family is extremely poor. If things keep going like this, my cute little brothers will have such a pitiful life.

I don't know if I was reincarnated or possessed, but I don't have any cheat abilities either. I have to find a way to make it work using only lifestyle magic.
